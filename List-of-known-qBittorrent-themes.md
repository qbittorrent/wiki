# Information

A non-exhaustive list of FOSS GUI themes developed for qBittorrent by the community.

They are provided on a best-effort basis as a community initiative and not officially supported. Issues with the themes should be reported on their respective repositories.

If you know of more, feel free to add a link to the repository, along with a short description.

For usage, see [How to use custom UI themes](https://github.com/qbittorrent/qBittorrent/wiki/How-to-use-custom-UI-themes).

# Themes
Dual means the theme complies with qBittorrent's Light/Dark color scheme setting.

Single means it has a fixed color scheme.
